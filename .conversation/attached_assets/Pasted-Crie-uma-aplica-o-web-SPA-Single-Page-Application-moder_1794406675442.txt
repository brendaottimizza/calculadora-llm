Crie uma aplicação web SPA (Single Page Application) moderna, responsiva e altamente performática para uma Calculadora de Custos e Comparação de LLMs. Utilize React, Tailwind CSS e Recharts para garantir um visual fluido, dinâmico e premium, superando a estética engessada de ferramentas tradicionais de dados.

Consumo de Dados via API e Fallback:
1. Integração com API (OpenRouter): Ao carregar o app, faça uma requisição HTTP (fetch) para a API pública do OpenRouter (https://openrouter.ai). Extraia dinamicamente: o nome do modelo, o provedor, a janela de contexto e os preços de 'prompt' (entrada) e 'completion' (saída) convertidos para o custo por 1 Milhão de tokens.
2. Banco de Dados Local (Fallback/Mock): Caso a API falhe ou demore a carregar, tenha uma lista local mockada com modelos principais (OpenAI: GPT-4o-mini, GPT-5.6 Luna; Anthropic: Claude Haiku Latest, Claude Haiku 5.5, Claude Haiku 4.5; AionLabs: Aion 3.5, Aion 3.5 Mini, Aion-2.0, Aion-3.0, Aion-3.0-Mini) para que o app nunca fique vazio. Garanta que os modelos da AionLabs sempre apareçam na lista, mesmo se não estiverem na API externa.

Diretrizes de Design Premium e UI:
1. Cores e Fundo: Use um tema escuro profundo (Dark Mode premium). O fundo principal deve ser azul-escuro/grafite quase preto (#090d16 ou #0b0f19). Os cards devem usar uma cor ligeiramente mais clara (#131a26), com bordas arredondadas generosas (rounded-2xl) e uma borda cinza sutil (border-slate-800).
2. Efeitos Visuais: Adicione efeitos de transição suave (duration-300) e uma leve elevação/brilho azulado (shadow-[0_0_15px_rgba(59,130,246,0.1)]) quando o usuário passar o mouse (hover) sobre os cards de custos.
3. Tipografia: Use uma fonte moderna e limpa sem serifa (como Inter ou Plus Jakarta Sans) com hierarquia visual clara: títulos grandes e marcantes em branco, textos de suporte e labels em cinza claro (text-slate-400).
4. Layout Geral: Um header centralizado no topo com o título "Calcule e Compare Custos de LLMs" e o subtítulo "A ferramenta definitiva para desenvolvedores e empresas otimizarem seus gastos com IA...". No canto superior direito, inclua ícones discretos para GitHub e redes sociais.

Funcionalidades e Lógica de Negócio:
1. Painel Lateral de Entrada (Controles de Usuário):
   - Campo "Selecionar Modelos": Deve ser um Combobox moderno com busca instantânea que filtre a lista trazida pela API. Quando os modelos forem selecionados, eles devem aparecer como "tags/badges" elegantes com um botão (x) para remover, empilhados de forma limpa.
   - Input para "Tokens de Entrada (Prompt)": Numérico, aceitando valores altos com formatação visual de milhar (padrão inicial: 1.000.000).
   - Input para "Tokens de Saída (Completion)": Numérico, aceitando valores altos com formatação visual de milhar (padrão inicial: 1.000.000).
   - Input para "Taxa de conversão (USD para local)": Para converter o valor final de Dólar para Real brasileiro (R$) (padrão inicial: 5.4).

2. Painel Central de Resultados (Dashboard Reativo):
   - Card "Resumo da Comparação": Exibe um texto gerado dinamicamente destacando de forma automática qual é a opção mais barata dentre as selecionadas, o custo total em USD e o equivalente convertido em R$ (ex: "Com base nos modelos e tokens selecionados, a opção mais econômica é o Anthropic: Claude Haiku Latest, com um custo total de $0.60 (~R$ 3,24).").
   - Card "Gráfico Comparativo de Custos (USD)": Use Recharts para renderizar um gráfico de barras verticais empilhadas (Stacked Bar Chart). Cada barra representa um modelo selecionado, dividindo a cor do "Custo de Entrada" (Azul Elétrico Neon) e "Custo de Saída" (Laranja Vibrante Neon). Use cantos arredondados nas barras (radius) e um tooltip customizado com fundo escuro e efeito de desfoque (backdrop-blur-md) ao passar o mouse.
   - Seção "Detalhes de Custo por Modelo": Uma grade (grid) de cards verticais reativos. Cada card representa um modelo ativo na comparação e deve exibir de forma organizada: Nome e Provedor, tamanho do Contexto, Custo de Entrada (em USD e R$), Custo de Saída (em USD e R$) e o Custo Total em destaque colorido. Adicione um pequeno ícone de estrela de "favorito" clicável no canto superior direito de cada card.

Por favor, monte a estrutura completa do projeto, instale as dependências necessárias e garanta que todos os cálculos atualizem instantaneamente na tela assim que o usuário alterar os tokens ou a taxa de conversão.
