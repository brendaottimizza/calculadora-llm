A aplicação é propriedade da empresa Ottimizza e deve usar sua identidade corporativa.

O nome Ottimizza exibido como texto deve usar Oxanium estritamente em peso Semi-Bold (600), com espaçamento reduzido, substituindo a orientação anterior de usar Orbitron black. A cor é branca no tema escuro e azul-marinho no claro. Não exibir o link social X no cabeçalho.

O usuário substituiu a orientação de tema fixo por alternância funcional entre claro e escuro, com preferência persistida. O tema escuro continua sendo o padrão e deve preservar seu visual original.

**Why:** O usuário pediu para tornar a aplicação propriedade oficial da Ottimizza.

**How to apply:** Em ajustes de branding, preservar as seções, cores escuras, inputs, lógica de cálculo, gráfico, funcionalidades e integração de dados existentes, conforme solicitado.
